Sovereign Gurmukhi typography archive celebrating Punjabi literature and Khalsa heritage with Anek Gurmukhi, Baloo Paaji 2, Noto Sans & Serif Gurmukhi.

## 🌟 Typographic Specimen

```text
ਸਭ ਮਨੁੱਖ ਆਜ਼ਾਦ ਅਤੇ ਸਨਮਾਨ ਅਤੇ ਅਧਿਕਾਰਾਂ ਵਿੱਚ ਬਰਾਬਰ ਪੈਦਾ ਹੋਏ ਹਨ
```

## ⚡ Fast Installation

### Linux & macOS (Bash)
```bash
curl -fsSL https://raw.githubusercontent.com/Open-Typography-Foundation/Gurmukhi-Punjabi-Fonts-Archive/main/install.sh | bash
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/Open-Typography-Foundation/Gurmukhi-Punjabi-Fonts-Archive/main/install.ps1 | iex
```
